# Delta 实机与 sim2real

当前阶段：电机资料评审与 ROS 2 实施规划。机械臂 CAD、实际连杆尺寸和电路仍待提供；本目录尚无可驱动电机的程序，也未进行通电或实机验证。`../delta_sim/` 仍是独立仿真，不把它的机械参数视为真实设备参数。

建议阅读顺序：

1. [电机手册解读](MOTOR_MANUAL_NOTES.md)：确认了什么、协议有哪些歧义、还需哪些资料。
2. [实施 pipeline](PIPELINE.md)：从硬件接口冻结到 ROS 2 在线击球的分阶段任务及验收。
3. [待确认参数表](config/hardware_pending.yaml)：记录后续需要实测或由厂家确认的参数。它是资料模板，不是 ROS 2 可加载配置，更不是上电配置。

```text
delta_real/
├── README.md                     # 当前状态、阅读顺序与文件用途
├── MOTOR_MANUAL_NOTES.md          # 九页电机手册的技术摘要、页码和疑点
├── PIPELINE.md                   # ROS 2 / ros2_control 架构、实施步骤与验收
└── config/
    └── hardware_pending.yaml     # 已知规格与未确认硬件参数；禁止直接用于驱动
```

当前只建立文档和参数模板。ROS 2 工作空间、驱动、launch、URDF/Xacro 和实机控制器将在相应阶段建立，不提供可能被误认为已验证的空驱动或上电命令。

资料来源为用户提供的《DM-J4310-2ECV1.1 减速电机使用说明书》，V1.0，2023-11-16，共 9 页。原始 `达妙电机.pdf` 留在本地 robot 目录，未修改，也未复制上传到仓库。本目录保存自行整理的技术摘要，读者须核对实际电机铭牌、固件及对应版本官方资料。

下一步最需要收到：实物铭牌和固件版本、完整《达妙驱动控制协议》及调试助手资料、CAN 接口方案和电路原理图。机械结构资料可稍后接入，详见 pipeline 中各阶段的依赖关系。
